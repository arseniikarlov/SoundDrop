# SoundDrop

`SoundDrop` это Android-приложение на Kotlin + Jetpack Compose, которое реагирует на движение телефона и воспроизводит звук:

- встроенный стон через системный `TextToSpeech`
- твои собственные аудиофайлы
- смешанный режим, где встроенный звук и загруженные файлы чередуются

## Что умеет сейчас

- красивый стеклянный интерфейс с тёмным фоном, бликами и полупрозрачными карточками
- срабатывание на встряску
- срабатывание на лёгкий подброс с поимкой
- отдельные переключатели для каждого типа движения
- регулировка чувствительности, порога удара, паузы между срабатываниями и громкости
- загрузка сразу нескольких своих звуков через системный файловый picker
- сохранение настроек и списка выбранных аудиофайлов между запусками
- тестовая кнопка, чтобы проверить звук без тряски телефона

## Как пользоваться

1. Установи APK на Android-устройство с акселерометром.
2. Открой `SoundDrop`.
3. В верхней карточке включи режим мониторинга.
4. Нажми `Тест`, чтобы проверить, как звучит встроенный звук.
5. Если хочешь свои звуки, нажми `Загрузить звуки` и выбери аудиофайлы.
6. Выбери режим:
   - `Встроенный` — только TTS
   - `Только свои` — только загруженные файлы
   - `Смешанный` — приложение чередует оба варианта
7. Подстрой чувствительность, если приложение срабатывает слишком часто или слишком редко.
8. Слегка тряхни телефон или сделай аккуратный короткий подброс.

## Сборка и запуск

```bash
./gradlew test
./gradlew assembleDebug
```

Готовый debug APK после сборки:

```text
app/build/outputs/apk/debug/app-debug.apk
```
