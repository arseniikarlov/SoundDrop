# Fall Ouch!

`Fall Ouch!` это Android-приложение на Kotlin + Jetpack Compose, которое реагирует на движение телефона и воспроизводит:

- встроенный русский мат через системный `TextToSpeech`
- твои собственные аудиофайлы
- смешанный режим, где TTS и загруженные файлы чередуются

## Что умеет сейчас

- красочная launcher-иконка с падающим телефоном
- стеклянный тёмный интерфейс с glow-эффектами
- срабатывание на встряску
- срабатывание на лёгкий подброс
- foreground service для работы в фоне
- постоянное уведомление, пока включён мониторинг
- отдельные переключатели для встряски и подброса
- настройка чувствительности, порога удара, паузы между срабатываниями и громкости
- загрузка нескольких своих звуков через системный picker
- сохранение настроек и выбранных аудиофайлов между запусками
- кнопка `Тест`, чтобы проверить звук без тряски

## Как пользоваться

1. Установи APK на Android-устройство с акселерометром.
2. Открой `Fall Ouch!`.
3. Включи верхний переключатель.
4. После этого приложение поднимет фоновый мониторинг и покажет уведомление.
5. Нажми `Тест`, чтобы проверить встроенный мат или свои файлы.
6. Если хочешь кастомные звуки, нажми `Загрузить звуки`.
7. Выбери режим:
   - `Встроенный` — только русский мат через TTS
   - `Только свои` — только загруженные файлы
   - `Смешанный` — приложение чередует оба варианта
8. Сверни приложение: пока переключатель включён и уведомление висит, мониторинг продолжит работать в фоне.
