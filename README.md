# Fall Ouch!

`Fall Ouch!` это Android-приложение на Kotlin + Jetpack Compose, которое реагирует на движение телефона и воспроизводит:

- отдельные звуки на `Тряску` и `Падение`
- встроенные не-матные MP3
- встроенный русский мат через системный `TextToSpeech`
- собственные загруженные аудиофайлы

## Что умеет сейчас

- красочная launcher-иконка с падающим телефоном
- стеклянный тёмный интерфейс с glow-эффектами
- срабатывание на встряску
- срабатывание на лёгкий подброс
- foreground service для работы в фоне
- постоянное уведомление, пока включён мониторинг
- новый `Home`-экран без шапки с большим power-toggle
- отдельный экран `Звуки` с вкладками `Библиотека / Мои / Популярно`
- отдельный экран `Настройки`
- стеклянный виджет `Fall Ouch!` для главного экрана
- быстрый toggle мониторинга прямо из виджета
- отображение звука на `Тряску` и `Падение` в приложении и виджете
- отдельные переключатели для встряски и подброса
- раздельная установка звука на `Тряску`, `Падение` или сразу на оба события
- предпрослушка звука до установки
- отдельное разделение встроенной библиотеки на `Не мат` и `Мат`
- настройка чувствительности тряски, чувствительности падения и громкости
- предустановленный не-матный пакет из файлов:
  `doh1.mp3`, `untitled2.mp3`, `tom_scream.mp3`, `o-kurwa.mp3`, `sdfds.mp3`, `5-gta-wasted.mp3`
- загрузка нескольких своих звуков через системный picker
- сохранение настроек и выбранных аудиофайлов между запусками
- заглушка под `Создать` из видео/записи экрана как следующий шаг

## Как пользоваться

1. Установи APK на Android-устройство с акселерометром.
2. Открой `Fall Ouch!`.
3. На `Home` включи большой power-toggle.
4. В первой панели посмотри, какой звук стоит на `Падение` и какой на `Тряску`.
5. Нажми `Настроить`, чтобы перейти в меню `Звуки`.
6. В `Библиотеке`, `Моих` или `Популярно` прослушай нужный звук.
7. Установи его на `Тряску`, `Падение` или `Оба`.
8. Вернись на `Home` и при необходимости подстрой чувствительность и громкость.
9. Сверни приложение: пока режим включён и уведомление висит, мониторинг продолжит работать в фоне.

## Виджет

После установки приложения можно добавить виджет `Fall Ouch!` на главный экран:

1. Зажми пустое место на домашнем экране Android.
2. Открой раздел `Виджеты`.
3. Найди `Fall Ouch!`.
4. Перетащи виджет на экран.

Виджет умеет:

- показывать, активен ли фоновый мониторинг
- показывать отдельные назначения на `Тряску` и `Падение`
- открывать приложение
- включать и выключать мониторинг одной кнопкой

Для lock screen я добавил совместимые `keyguard`-метаданные и отдельную layout-точку. Но на стандартном Android поддержка lock screen widgets не универсальна: в актуальной Android Developers docs для app widgets указано, что для Android 5.0+ универсально поддерживается только `home_screen`, поэтому отображение на экране блокировки зависит от конкретного устройства, лаунчера или keyguard-host.
